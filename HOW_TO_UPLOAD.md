# Upload the Awesome-style README to GitHub

Repository: https://github.com/gordonowusuboateng/generative-autonomous-driving-models

1. Open the repository, select `README.md`, then click the pencil icon (Edit this file).
2. Replace the contents with the new `README.md` from this package and click **Commit changes**.
3. Replace the repository's `CONTRIBUTING.md` in the same way.
4. Optionally upload `data/curated-papers.csv` and `data/curated-papers.json` by dragging the extracted `data` folder under Add file > Upload files, preserving its folder path.
5. Verify the embedded image `assets/taxonomy-framework.png` renders and the paper links open.

You do **not** need GitHub Pages, `index.html`, or `style.css`. The README is the project home page.

This package **has not been written to GitHub** because the connected GitHub app previously returned a 403 error for repository writes.

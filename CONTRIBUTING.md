# Contributing

Please open an issue or pull request with a full paper title, authors, venue/year (or preprint status), original paper URL, code URL if available, relevant taxonomy category, conditioning input, generated output, and the interface to driving decisions.

Include evidence for claimed functional convergence; architectural integration or a shared backbone alone is insufficient. Distinguish semantic grounding from executable VLA systems. Verify all links and do not upload copyrighted PDFs or third-party dataset content without permission.
